# AuraOS Web Experience

A fully self-contained, browser-based operating system simulation built in a single HTML file. 

## 🚀 Features

* 🖥️ Desktop environment with draggable windows
* 📂 Virtual File System (in-memory)
* 🧠 Window manager (open, minimize, maximize, focus)
* 📌 Start menu & taskbar
* 📝 Built-in apps:

  * Notepad
  * Terminal (shell + Python simulation)
  * File Explorer
  * Paint
  * Calculator
  * Snake Game
  * ⚡ Boot screen + BSOD easter egg
